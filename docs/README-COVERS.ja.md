# カバー曲の生成

カバー生成は通常の生成キューを使用しますが、結果は新しい曲として保存されます。元音源は採譜と比較に使用し、YuE2には互換性のあるABC譜を音楽的な条件として渡します。既存の曲、音声、譜面は上書きされません。

## 操作手順

1. 保存済みの曲からカバー操作を開くか、カバー画面でWAV、FLAC、MP3、OGG、またはUTF-8のABCファイルをアップロードします。
2. 保存済みのABC譜があれば再利用します。元音源が音声のみでABC譜がない場合は採譜を依頼します。採譜後はABC譜の確認画面で停止し、自動的には生成を開始しません。
3. 採譜に関する警告を確認し、必要ならABC譜を編集します。実際に使用するABC譜を確認してください。
4. Lyrics、Style、Seedを入力します。外部音源の歌詞はユーザーが用意してください。このアプリは歌詞の認識・生成を行いません。
5. 確認内容を承認し、新しいジョブとしてカバー生成を送信します。

音声のアップロードは100 MiB以下、長さ0.1秒～20分、1または2チャンネル、サンプリング周波数8～96 kHzに制限されます。ABC譜の入力は256 KiB以下です。アプリは設定済みのYuE用Python環境でアップロード音声を検証し、アップロードされたファイルとプレビューを実行時データディレクトリに保存します。

## ABC譜の扱い

アプリはYuE公式の補助ツール `skills/yue2-music/scripts/abc_tools.py` を読み取り専用で呼び出します。このツールが扱うYuE2 nativeの2声部ABC形式に対応しています。`melody`モードでは、対応するコード記号を取り除き、VocalとInsのパートを保持します。`full`モードでは、編集後のABC譜を変更せずに渡します。カバー生成では`off`モードを使用できません。非対応のABC記法は推測して処理せず、修正が必要な入力として拒否します。譜面の検証に通っても、生成音声でメロディー、歌声、波形が完全に再現される保証はありません。

補助ツールがYuE用Python環境から導かれる場所にない場合は、`config.local.json` に `abc_tools` を設定してください。この公開用ディレクトリには補助ツールを含めていません。YuE公式配布物から入手し、利用条件を確認してください。

## SheetSage2による採譜の設定

音声の採譜には、SheetSage2専用のPython環境を使用します。ワーカーはローカルの `SheetSage2.modeling_sheetsage2.SheetSage2Model` パッケージを直接インポートし、`from_pretrained(..., local_files_only=True)` を呼び出します。Transformersの `AutoModel.from_pretrained(...)` を使ったセットアップだけでは、このワーカーが必要とするパッケージのインポート条件を満たしません。

`./setup.sh --stage cover` と[日本語導入ガイド](INSTALL.ja.md)を使用してください。別venv、公式SheetSage2・MERTの固定revision、アクセス承認、ローカル統合モデルの作成、`sheetsage_python`／`sheetsage_model` の設定、直接クラスのロード確認をまとめています。ワーカーには統合モデルの隣にある `SheetSage2/` ソースと `melody_only` 対応が必要です。UIの「設定済み」はファイル存在確認であり、重みのロード成功を保証しません。対象revisionの条件確認先は [EXTERNAL_DEPENDENCIES.ja.md](EXTERNAL_DEPENDENCIES.ja.md) にあります。

## Motif機能で必要なFFmpeg

Motifの音声切り出しは現在 `/usr/bin/ffmpeg` 固定です。FFmpeg 6.1と共有ライブラリの確認は[日本語導入ガイド](INSTALL.ja.md)を参照してください。Coverの採譜はこの固定パスを直接使いませんが、SheetSage2の音声処理に依存します。

## 保存データとプライバシー

元音源、プレビュー音声、ABC譜、採譜結果、ジョブのメタデータは、設定された `data_dir` 以下に保存されます。ユーザーの音声や歌詞が含まれる場合があります。実行時データディレクトリは非公開でバックアップし、ソースの公開物に加えたり、公開Issueに添付したりしないでください。
