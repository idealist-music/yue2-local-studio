# ABC ↔ MIDI Round-Trip Editing

From **Export MIDI** on a song's details page, you can export a saved ABC score as a Type 1 MIDI file. Choose the entire song, a detected section, a voice, or a range of measures. The downloaded round-trip ZIP contains `score.mid`, `source.abc`, `sidecar.json`, and `README.txt`. Vocal and Ins are separate tracks, and the PPQ resolution is 15360.

Edit the Vocal and/or Ins tracks in your DAW, then upload the MIDI file alone through **Import MIDI** in the app. Select the target song, score version, tracks, and start and end measures. Review the analysis and the range of changes before saving a new ABC version. After saving, use the normal score regeneration action to generate audio.

For API use, send the MIDI file as `application/octet-stream` to `POST /api/midi/imports`. You can then optionally send the sidecar to `POST /api/midi/imports/{id}/sidecar`, using the returned ID. A sidecar from the server export is checked against the original version ID, ABC SHA-256, snapshot SHA-256, PPQ, voices, and range. A changed MIDI SHA-256 after DAW editing produces a difference warning. Run `preview` only after explicitly assigning tracks and channels; `save` rechecks the preview token and the score HEAD. A MIDI file on its own can also be used to create a new native ABC score without chords via `.../{id}/new-song` with `cot=melody`.

In the UI, select a score version on the song's details page, then choose Vocal, Ins, or both; a section or measure range; and either MIDI alone or the ZIP package. When importing, inspect each candidate's track number, channel, name, note count, pitch range, and overlaps. Assign each candidate to Vocal, Ins, or Ignore. Multiple candidates are not confirmed automatically. If you use a sidecar, validate it separately and review any warnings about the target song, version, range, and hashes before running the analysis. Without a sidecar, manually confirm the target song, version, and start and end measures.

The shortest DAW workflow is: (1) download the round-trip ZIP using **Export MIDI** on the song's details page; (2) import `score.mid` from the ZIP into your DAW; (3) change just one note in Vocal or Ins; (4) export a MIDI file, not a WAV file, in SMF Type 0 or 1 format with PPQ timing; (5) select the `.mid` file in **Import MIDI** and, if needed, validate the ZIP's `sidecar.json` separately; (6) assign track × channel and confirm the target version, measures, transposition, and quantization; (7) review the note differences in the preview and choose **Save as New ABC Version**; (8) choose **Regenerate from This Version**. WAV is for listening or exporting audio and cannot be used as input to MIDI round-trip editing.

The preview shows the number of quantization changes, the maximum and total timing deviations, information that will be lost, changed measures, estimated duration, and the ABC score that would be generated. **Save as New ABC Version** and **Regenerate from This Version** are separate actions. Regeneration starts with the target song's Style, Lyrics, and Seed; edit them in the normal form if needed before generating. If the target song has no ABC score, use Cover transcription or the separate path for creating a new song's ABC from MIDI alone.

Supported MIDI files use SMF Type 0 or 1 with PPQ time division. Type 2, SMPTE timing, RMID, polyphony, drum channels, notes outside the target range, and malformed note-on/note-off pairs are rejected. Performance data other than velocity, including CC, pedal, pitch bend, and SysEx, is not transferred to ABC and is reported as information loss. Valid ABC time signatures, keys, and section positions are recorded in the conductor track and sidecar; their state is carried forward to the start of the selected range.

Importing MIDI replaces only a selected passage of equal duration. Other score versions are retained, and the source song and existing audio are not overwritten. If you edit ABC outside the app, ensure that it follows the official YuE2 native ABC format. Creating a new song from MIDI alone and transcribing a Cover use separate workflows.

If a problem occurs, you can stop the app while preserving the saved files under `data/midi/exports/` and `data/midi/imports/`. Older features ignore the added MIDI versions and operation records; normal generation, Cover, Motif, and LAN settings remain available.

For recovery, stop the app and copy the SQLite backup at `data/backups/midi-schema-<UTC>.sqlite3`, along with `data/score_versions/` and `data/midi/`, to another location. Existing ABC scores and audio are not overwritten. If the MIDI end time does not match the duration of the target range, the initial version stops without saving. There is no option to pad with rests, scale time, or truncate the MIDI before saving.
