# フレーズから作曲 / Motif Song

Motif Song は、元音源の指定区間だけを SheetSage2 で採譜し、Style と Lyrics から YuE2 が作る全曲プランへ組み込む機能です。Cover の素材と保存場所、処理経路は共有しません。

1. 「フレーズから作曲」を開き、保存済みの元曲または音源を選びます。
2. 開始秒・終了秒、Style、Lyrics、Seed、用途、挿入先を入力して条件を保存します。
3. 区間を切り出し、採譜結果を確認します。採譜が成功したあと「全曲プランを作る」を押します。
4. 基本プランのセクション候補を確認し、モチーフをABCへ組み込みます。編集済みABCを確認してから生成します。

処理は既存の生成キューで直列に実行されます。採譜・プラン作成・音声生成はGPUを使うため、処理中は状態とログを確認してください。元音源、区間音源、採譜ABC、基本プラン、編集ABC、検証結果は `data/motifs/<id>/` に別々に保存されます。

初版はYuE2 native ABCの全小節を対象とし、異なる小節数のモチーフを自動的に切り詰めたり量子化したりしません。対象セクションが曖昧、拍子が異なる、未対応記法が含まれる場合は停止します。歌詞の自動認識や元歌手の声の再現は行いません。

SheetSage2 は `sheetsage_python` と `sheetsage_model` で指定した専用環境を使います。YuE2環境の依存関係は変更しません。

音源区間の切り出しには FFmpeg 6.1 と共有ライブラリが必要です。現行コードは `/usr/bin/ffmpeg` を直接呼び出します。FFmpegは同梱しません。公式の配布・条件確認先は[外部依存物ガイド](EXTERNAL_DEPENDENCIES.md)を参照してください。
