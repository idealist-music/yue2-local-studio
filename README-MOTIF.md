# Motif Song

Motif Song uses SheetSage2 to transcribe only a selected excerpt from a source recording, then incorporates that motif into a full-song plan generated by YuE2 from your Style and Lyrics. It uses separate assets, storage, and processing paths from the Cover feature.

1. Open **Create from a Motif** and select a saved source song or audio recording.
2. Enter the start and end times in seconds, Style, Lyrics, Seed, intended use, and insertion target, then save the settings.
3. Extract the excerpt and review the transcription. Once transcription succeeds, click **Create full song plan**.
4. Review the candidate sections in the base plan and incorporate the motif into the ABC score. Review the edited ABC before generating audio.

Tasks run sequentially through the existing generation queue. Transcription, planning, and audio generation use the GPU, so monitor the status and logs while processing. The source recording, extracted excerpt, transcribed ABC, base plan, edited ABC, and validation results are saved separately under `data/motifs/<id>/`.

The initial version works with complete measures in YuE2's native ABC format. It does not automatically truncate or quantize motifs whose measure counts differ from the target passage. Processing stops if the target section is ambiguous, the time signatures differ, or unsupported notation is present. This feature does not automatically transcribe lyrics or reproduce the original singer's voice.

SheetSage2 runs in the dedicated environment specified by `sheetsage_python` and `sheetsage_model`. Dependencies in the YuE2 environment are left unchanged.
